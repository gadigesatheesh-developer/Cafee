☕ Café Website

A modern and responsive café website built using **HTML**, **CSS**, and **JavaScript**.  
This project includes a home page, special combos, gallery section, beverages, and customer reviews.

---

## 🚀 Features

- Fully responsive design (mobile + desktop)
- Modern hero section
- Image gallery
- Menu section with beverages & combos
- Swiper slider for reviews
- Smooth mobile navigation
- Clean and simple UI

## 📱 Responsive Design

This website is optimized for:

- Mobile devices  
- Tablets  
- Desktop screens  

Using media queries and flexible layouts.

📌 How It Works

This project is fully responsive, meaning it automatically adjusts to different screen sizes — desktop, tablet, and mobile. The responsiveness is achieved through a combination of Flexbox, CSS Grid, and media queries.
